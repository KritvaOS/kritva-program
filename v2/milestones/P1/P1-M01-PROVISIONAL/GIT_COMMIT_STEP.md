# P1 STUDIO — Git Commit Step

Required sequence for recording work in this milestone.

1. Work on a branch named `p1/<task-id>-<short-name>`; do not commit directly to `main` once review is required.
2. Confirm the task's `ACCEPTANCE_CRITERIA.md` checklist is evidenced (evidence type labelled: software / simulation / physical).
3. Update [TASKS.md](TASKS.md) statuses and this milestone's [CHANGELOG.md](CHANGELOG.md) if the plan changed.
4. Commit with a message referencing the task ID; one logical change per commit.
5. Push and record the commit SHA in the task record (Git sync: COMMITTED → SYNCED).
6. After review approval, update [../../../tracking/STATUS.md](../../../tracking/STATUS.md).

A commit is evidence of change, not of acceptance.
